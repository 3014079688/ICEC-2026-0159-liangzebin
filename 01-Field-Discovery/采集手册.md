# 课题 08 数据采集手册（Phyphox）

> 目标：采集 **4 种状态** 的三轴加速度数据 —— 静止 / 平地慢走 / 快跑 / 上下楼梯。
> 交付物：4 份原始 CSV + 可视化图 + 能区分动作的阈值规则。

---

## 一、先明确三个决定（做错了要重采）

| 决定 | 选什么 | 为什么 |
| --- | --- | --- |
| **用哪个实验** | Phyphox → **Acceleration with g**（含重力的加速度） | 含 g 才能从 `az ≈ 9.81` 判断手机姿态；静止态的判据也依赖它 |
| **手机放哪** | **全程固定在同一个位置**，推荐裤兜（同侧）或腰包 | 位置一变，振幅、主频全变，数据就没法横向对比了 |
| **每段多长** | **≥ 60 秒** | 30 秒样本太少，分窗后每类只有十几个窗口，统计不可靠 |

> ⚠️ 这三条是整套实验的**前提**。中途换位置 = 数据作废。

---

## 二、采集步骤

### 1. 装 App
- iOS / Android 应用商店搜 **Phyphox**（免费，亚琛工业大学出品）
- 打开后允许「运动与健身」权限

### 2. 找到实验
首页 → **Acceleration with g**（中文版叫「含 g 的加速度」）

进入后先看右上角，确认：
- 采样率显示 **≥ 50 Hz**（不同手机不同，记录下你的实际值）
- 三条曲线在动

### 3. 四段采集（每段 ≥ 60 秒）

按这个顺序做，中间可以休息：

| 序号 | 状态 | 具体怎么做 | 建议时长 |
| --- | --- | --- | --- |
| 01 | **静止** | 站直不动，手不要碰手机，保持正常呼吸 | 60 s |
| 02 | **平地慢走** | 正常步速，走直路，不要刻意放慢或加快 | 60 s |
| 03 | **快跑** | 慢跑或快跑，保持自己能坚持的速度 | 60 s |
| 04 | **上下楼梯** | 连续上下一段楼梯，正常步速，抓稳扶手 | 60 s |

**每段的操作细节：**
1. 点开始录制
2. **先静止 3 秒**（这段是基准，能自动算重力方向）
3. 做动作
4. 结束前**再静止 2 秒**
5. 点停止 → 立刻导出（Phyphox 只保留最后一次记录）

### 4. 导出 CSV

实验页面右上角 **⋮ → Export Data → CSV** →
选「Export raw data」→ 通过邮件/微信/网盘发到自己电脑。

文件名改成规范格式（脚本靠文件名识别状态）：

```
01-still.csv     静止
02-walk.csv      平地慢走
03-run.csv       快跑
04-stair.csv     上下楼梯
```

> 脚本认这些关键字：`still/static/idle/静止`、`walk/slow/慢走`、`run/fast/跑`、`stair/楼梯`

### 5. 放进仓库

把 4 个 CSV 放到：
```
01-Field-Discovery/raw_data/
```

然后运行分析：
```bash
python 01-Field-Discovery/tools/analyze_gait.py
```

## 三、采集时的注意事项

- **安全第一**：上下楼梯别抢速度，快跑选操场跑道或空地
- **手机固定**：用紧口袋，或塞进腰包拉好拉链，避免晃动
- **同一双鞋、同一条路**：能把「鞋子/地面」这个干扰变量控制住
- **每次动作前重置**：Phyphox 只存一次记录，导完再录下一段
- **记录元信息**：手机型号、采样率、放置位置、鞋子、地点、时间 —— 这些要写进报告

## 四、常见错误对照表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 静止态 `svm_std` 很大（>1） | 手机没放稳，或手扶着手机 | 放桌上或兜里，别碰 |
| 慢走和静止主频差不多 | 走得太慢，或手机在包里晃动 | 正常步速，固定好手机 |
| 快跑和楼梯分不开 | 上下楼速度太快 | 上下楼用**正常步速**，跑用**跑步步速** |
| CSV 打不开 / 列名乱码 | 编码问题 | 用 Excel「数据 → 从文本」选 UTF-8；脚本已做兼容 |
| 图里中文变成方框 | 缺中文字体 | 脚本会自动找「微软雅黑」，找不到会提示；Windows 一般都有 |

## 五、判据的物理直觉（写报告用得上）

| 状态 | 时域 | 频域 |
| --- | --- | --- |
| **静止** | 只有呼吸级微动，`svm_std` < 0.3 | 无明显主频 |
| **慢走** | 每步一次冲击，`az` 呈 2 倍频周期 | 主频 **1.5–2.5 Hz**（≈ 90–150 步/分） |
| **快跑** | 冲击大、有腾空相，`svm_max` 明显更高 | 主频 **2.5–4 Hz**，且高次谐波更丰富 |
| **上下楼梯** | 竖直位移大，`az_mean` 有系统偏移 | 主频比平地走**低**，但单次幅值更大 |

> 这四条只是**先验预期**，最终阈值必须用你**自己的数据**跑出来 ——
> 不同手机传感器量程、不同人的步态差异都很大，照抄别人的阈值一定翻车。
