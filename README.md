## 二、选题说明

| 项目 | 内容 |
| --- | --- |
| 选题名称 | **课题 08 · 多姿态步态加速度特征采集与对比** |
| 选题背景 | 手机内置加速度计成本极低、普及率极高。但静止、慢走、快跑、上下楼梯这几种日常状态的加速度信号长什么样、能否用一条简单阈值区分，缺少可直接复用的实测依据。这是行为识别、运动量统计、老人跌倒监测的基础环节。 |
| 目标用户 / 场景 | 手机端行为识别、运动健康 App、独居老人看护 |
| 核心方案 | 用手机采集四类状态的三轴加速度，分窗提取时域与频域特征，找出可分离的特征区间，推导出能区分动作的阈值判据。 |
| 技术路线 | **采集**：Phyphox「含 g 的加速度」，≥50 Hz，每类 ≥60 s<br>**预处理**：去直流分量、2 s 滑动分窗（50% 重叠）<br>**特征**：合加速度 SVM 的均值/标准差/峰值/峰峰值、各轴标准差、过零率、主频（FFT）、变异系数<br>**判据**：按 p10–p90 区间考察各类间的可分离性，生成阈值链 |
| 预期成果 | 4 份原始 CSV + 3 张可视化图（波形/特征箱线图/频谱）+ 阈值规则文档 + 阶段一调研报告 |
| 可衡量指标 | ① 四类状态在至少 2 个特征上取值范围互不重叠<br>② 阈值判据在留出样本上的分类准确率 |

> 提示：选题说明是评委第一眼看到的东西，**建议控制在 300 字以内，先讲清「问题」再讲「方案」**。
