# 阶段三 · AI Collaboration（AI 协作记录）

> 目的：展示你**如何把 AI 当协作者用**——包含提问的进化、被推翻的假设、以及你自己的判断。

## 本目录放什么

- `ai-log.md` —— 关键对话记录主文件
- 可选的对话导出：`exports/YYYY-MM-DD-主题.md`

## `ai-log.md` 记录模板

```markdown
## 对话 01 ｜ 2026-10-XX ｜ 主题：跌倒检测算法选型

**背景**：我有什么约束（算力、成本、时延）

**我的提问（原始）**：
> 

**AI 的回答要点**：
- 

**我的判断 / 追问**：
- 哪些采纳了，为什么
- 哪些没采纳，为什么
- 追问了什么，AI 修正了什么

**结论与影响**：这条对话最终改变了项目里的什么决定
```

## 什么样的记录算「关键对话」

| ✅ 值得记 | ❌ 不必记 |
| --- | --- |
| 决定了技术路线的对话 | 「帮我写个 for 循环」 |
| AI 给出了错误答案、你识别并纠正了 | 纯语法查询 |
| 你通过反复追问把模糊需求逼成明确方案 | 无关闲聊 |
| AI 提出了你没想到的角度，改变了选题 | 复制粘贴的整段生成内容 |

## 提交检查清单

- [ ] 至少 **5 条**关键对话，覆盖不同阶段（选题 / 方案 / 实现 / 排错）
- [ ] 每条都写清「AI 说了什么」+「我怎么判断」
- [ ] 有至少 1 处你**否定了 AI 的建议**并说明理由
- [ ] 保留你提问的原始措辞，体现提问能力的进步
