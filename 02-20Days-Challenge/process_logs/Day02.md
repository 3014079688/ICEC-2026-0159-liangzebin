## 遇到的问题

**问题 1：环境里没有任何数据分析库**

- **现象**：`numpy / pandas / matplotlib / scipy` 全部未安装
- **尝试过的方案**：直接 `pip install` 会污染系统 Python
- **最终解决**：建独立虚拟环境后安装
  ```bash
  python -m venv C:/Users/ASUS/.workbuddy/binaries/python/envs/default
  .../Scripts/python.exe -m pip install numpy pandas matplotlib scipy
  ```

**问题 2：脚本第一版把演示产物写进了 raw_data/**

- **现象**：跑 demo 后 `raw_data/` 里混进了 `demo_*.csv`、`features_*.csv`
- **为什么是问题**：`raw_data/` 要提交原始数据，混进合成数据会让报告失去可信度
- **最终解决**：演示模式的产物全部改写到 `tools/_demo/`，并加进 `.gitignore`

**问题 3：不确定阈值能不能靠理论推出来**

- **结论**：不能。不同手机传感器量程、不同人步态差异很大，只能用**自己的数据**统计。
- **应对**：脚本不写死阈值，而是从实际数据里算 p10–p90 区间再推导，并检查区间是否重叠。
